학생 접속용 QR 코드

임시 미리보기 주소 감지됨

현재 화면은 C드라이브 로컬 파일(file:) 상태이므로 이대로 QR 코드를 생성하면 학생들이 접속할 수 없습니다. 아래 입력창에 배포된 실제 사이트 주소를 붙여넣어 주세요!

* C드라이브 메모장 상태에서 교실 화면에 QR을 띄울 때, 배포된 무료 사이트 주소를 여기에 한 번만 붙여넣어 주시면 해당 인터넷망 주소로 완벽히 연동된 전용 QR 코드가 동적으로 그려집니다.

교실 스크린이나 TV 화면에 이 팝업을 크게 띄워주세요.
학생들이 스마트폰 카메라로 스캔하면 바로 접속할 수 있습니다.

생성된 원격 연동 주소(URL)

웹 호스팅 배포(진짜 주소 만들기) 초간단 가이드

이 도우미 프로그램은 여러 학교의 선생님과 학생들이 다른 기기(스마트폰)에서 서로 실시간 동기화하여 사용하는 클라우드 방식입니다. 때문에 임시 주소에서 다운받은 파일 상태로는 기기 간에 데이터가 연동되지 않습니다. 아래 순서로 단 1분 만에 진짜 인터넷 주소를 띄워보세요!

배포 가이드 3단계
  1. 이 코드를 컴퓨터에 파일로 저장: 오른쪽 캔버스 화면의 전체 코드를 복사하여 컴퓨터 메모장에 붙여넣고, 바탕화면에 새 폴더를 만든 뒤 폴더 안에 index.html 이라는 이름으로 저장합니다. (저장할 때 파일 형식을 '모든 파일'로 선택해 주세요.)
  2. 무료 주소 발급 사이트 접속: 컴퓨터 브라우저로 무료 정적 배포 서비스인 Netlify Drop (app.netlify.com/drop) 사이트에 접속합니다.
  3. 폴더 그대로 드래그 앤 드롭: 가장 방금 생성한 바탕화면의 폴더 전체를 사이트 화면 한가운데에 그대로 드래그하여 올려놓습니다. 수초 이내에 전 세계 어디서든 접속 가능한 나만의 고유 진짜 주소(https://....netlify.app)가 무상 발급됩니다!
💡 선생님만의 실시간 기기 간 연동 가이드

동일한 실시간 클라우드를 활용해 여러 디바이스에서 데이터를 끊김 없이 주고받으려면 데이터베이스 연동이 필요합니다. 아래의 "실시간 클라우드 연동 설정" 가이드를 통해 평생 무료인 전용 파이어베이스를 연동해 보시기 바랍니다.

☁️ 100% 무료 실시간 클라우드 데이터베이스 연동

학교나 가정의 학생 기기들과 실시간으로 정보를 주고받으려면 평생 무료인 구글 파이어베이스(Firebase) 데이터베이스를 연동해야 합니다. 아래 순서대로 3분 만에 설정해 보세요!

⚙️ 초간단 연동 방법
  1. 구글에 파이어베이스 콘솔을 검색하여 접속합니다.
  2. [프로젝트 추가]를 누르고 프로젝트 이름을 자유롭게 적어 만듭니다.
  3. 왼쪽 메뉴에서 [Build] ➡️ [Firestore Database]를 누른 뒤 데이터베이스를 생성합니다. (테스트 모드로 생성해 주세요.)
  4. 메인 대시보드로 돌아와서 웹 앱 아이콘(</>)을 클릭해 앱을 등록합니다.
  5. 화면에 표시되는 설정 코드 중 firebaseConfig = { ... } 부분을 아래 입력창에 그대로 붙여넣어 주세요!
